# Keyboard shortcuts

## Drawing

| Key | Action |
|---|---|
| `S` / `Esc` | select (Esc also cancels the tool) |
| `L` / `Shift+L` | line / construction line |
| `R` / `Shift+R` | rectangle / center rectangle |
| `C` | circle |
| `A` / `Shift+A` | three-point arc / center arc |
| `P` | point |
| `D` | dimension |
| `X` | trim |
| `U` | measure (ruler) |
| `O` | offset |
| `G` | move / rotate the selection |
| `Q` | toggle construction |
| `F` | fit to screen |
| `Del` | delete the selection |

## Constraints (with a selection)

| Key | Constraint |
|---|---|
| `I` | coincident |
| `H` / `V` | horizontal / vertical |
| `T` | tangent |
| `E` | equal |
| `M` | midpoint |

## General

| Key | Action |
|---|---|
| `Ctrl+Z` | undo |
| `Ctrl+Shift+Z` / `Ctrl+Y` | redo |
| `Ctrl+A` | select all |
| `Ctrl+G` / `Ctrl+Shift+G` | group / ungroup |
| mouse wheel | zoom |
| middle or right button, or `Space` + drag | pan |

## Console

| Key | Action |
|---|---|
| `Enter` | run |
| `Tab` | complete commands, ids and variables |
| `↑` / `↓` | history |

## Schematic

| Key | Action |
|---|---|
| `W` | wire mode |
| `R` | rotate |
| `M` | mirror |
| `Del` | delete |
