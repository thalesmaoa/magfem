# Cite

If MagFEM helped your research or project, please cite it. The **Cite** button at the top of the app builds the
citation with today's access date and has copy buttons.

## Citation (APA)

Maia, T. (2026). *MagFEM: A Web-Based Magnetic Finite Element Analysis Tool* (Version 1.0.0) [Computer software].
Retrieved *access date*, from https://thalesmaia.com/tools/magfem-web/

## Citação (ABNT)

MAIA, Thales. **MagFEM: A Web-Based Magnetic Finite Element Analysis Tool**. Versão 1.0.0. [S. l.], 2026.
Software. Disponível em: https://thalesmaia.com/tools/magfem-web/. Acesso em: *data de acesso*.

## BibTeX

```bibtex
@software{maia2026magfem,
  author  = {Maia, Thales},
  title   = {{MagFEM}: {A Web-Based Magnetic Finite Element Analysis Tool}},
  year    = {2026},
  version = {1.0.0},
  url     = {https://thalesmaia.com/tools/magfem-web/},
  urldate = {YYYY-MM-DD},
  note    = {Accessed: YYYY-MM-DD}
}
```

Replace `YYYY-MM-DD` with the date you used MagFEM.
