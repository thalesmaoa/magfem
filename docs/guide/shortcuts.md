# Atalhos de teclado

## Desenho

| Tecla | Ação |
|---|---|
| `S` / `Esc` | selecionar (Esc também cancela a ferramenta) |
| `L` / `Shift+L` | linha / linha de construção |
| `R` / `Shift+R` | retângulo / retângulo pelo centro |
| `C` | círculo |
| `A` / `Shift+A` | arco por três pontos / arco pelo centro |
| `P` | ponto |
| `D` | cota |
| `X` | tesoura (aparar) |
| `U` | medir (régua) |
| `O` | offset |
| `G` | mover / girar a seleção |
| `Q` | alterna construção |
| `F` | ajustar à tela |
| `Del` | apagar a seleção |

## Restrições (com a seleção)

| Tecla | Restrição |
|---|---|
| `I` | coincidente |
| `H` / `V` | horizontal / vertical |
| `T` | tangente |
| `E` | igual |
| `M` | ponto médio |

## Geral

| Tecla | Ação |
|---|---|
| `Ctrl+Z` | desfazer |
| `Ctrl+Shift+Z` / `Ctrl+Y` | refazer |
| `Ctrl+A` | selecionar tudo |
| `Ctrl+G` / `Ctrl+Shift+G` | agrupar / desagrupar |
| roda do mouse | zoom |
| botão do meio ou direito, ou `Espaço` + arrastar | mover a vista |

## Console

| Tecla | Ação |
|---|---|
| `Enter` | executa |
| `Tab` | completa comandos, ids e variáveis |
| `↑` / `↓` | histórico |

## Esquemático

| Tecla | Ação |
|---|---|
| `W` | modo fio |
| `R` | girar |
| `M` | espelhar |
| `Del` | apagar |
